# 👟 Phố Step - Backend (Spring Boot REST API)

Đây là phần **RESTful API backend** cho website bán giày sneaker nam **Phố Step**, được xây dựng bằng Spring Boot.

> 🔗 Repo chính: [pho-step-backend](https://github.com/DevlinHoang1216/pho-step-backend.git)

---

## 🚀 Công nghệ sử dụng

- Java 17+
- Spring Boot 3+
- Spring Web (REST API)
- Spring Data JPA
- Spring Security (nếu dùng)
- JWT (Xác thực người dùng, nếu có)
- Oracle / MySQL (Cơ sở dữ liệu)
- Maven
